1. 요약

BABA Real-Time Chat Translator(이하 “본 앱”)는 사용자가 직접 위치를 정한 화면의 한 영역을 읽어, 그 안의 메시지를 인식하고 번역합니다. 이 절은 전체 내용을 짧게 밝히며, 이어지는 각 절이 세부 내용을 설명합니다.

  • BABA SOFTWARE는 어떠한 서버도 운영하지 않습니다. 본 앱에는 당사의 주소가 존재하지 않습니다. 당사로 전송되는 것은 없으며, 당사는 사용자나 사용자의 대화에 관한 어떠한 정보도 수신하지 않습니다.
  • 본 앱은 화면 전체가 아니라 하나의 영역만 캡처합니다. 그 위치와 크기는 사용자가 정하며, 캡처는 번역이 실행 중일 때 이루어집니다.
  • 번역을 위해서는 메시지 텍스트를 외부 서비스 한 곳으로 전송해야 합니다. 그 서비스는 사용자가 선택하고 사용자 본인의 API 키로 설정한 곳이며, 유일한 수신자입니다.
  • 캡처한 이미지는 기기 밖으로 나가지 않습니다. 다만 언어를 자동 감지로 두었거나 Windows가 읽을 수 없는 언어인 경우에는 이미지가 Google로 전송됩니다. 이미지를 받을 수 있는 서비스는 Google 하나뿐입니다. 이를 피하는 방법은 4절에 있습니다.
  • 캡처·인식·번역된 어떤 것도 디스크에 기록되지 않습니다. 본 앱이 기록하는 파일은 자신의 설정 파일 하나뿐입니다.
  • 분석 도구, 오류 보고, 업데이트 확인, 라이선스 확인이 일절 없습니다.

2. 화면 캡처

본 앱의 창에는 투명한 구멍(읽기 구멍)이 있으며, 사용자는 이것을 대화 프로그램의 메시지 목록 위에 놓습니다. 본 앱이 캡처하는 것은 그 구멍 뒤에 있는 화면의 사각형입니다. 그 위치와 크기는 사용자가 정합니다. 그 바깥은 캡처되지 않으며, 본 앱은 화면 전체를 캡처하지 않습니다.

캡처는 번역이 실행 중일 때 이루어집니다. 실행은 시작 버튼을 누를 때 시작되고 다시 누를 때 끝납니다. 캡처 간격은 기본 1.5초이며 설정에서 변경할 수 있습니다.

캡처가 한 가지 더 있으며, 설명을 빠짐없이 하기 위해 여기에 밝힙니다. 번역을 정지하면 이미 화면에 표시된 번역문은 사용자가 마저 읽을 수 있도록 일부러 남겨 둡니다. 그것이 남아 있는 동안 본 앱은 같은 사각형을 1초에 한 번 48×48 픽셀 지문으로 만들어 직전 것과 비교하며, 이는 그 아래의 대화가 바뀌었을 때 남은 번역문을 치우기 위한 것입니다. 이 지문에는 문자 인식을 수행하지 않으며, 이에 관한 어떤 것도 전송되지 않습니다. 기기 안에서 비교하고 폐기합니다.

캡처한 이미지는 컴퓨터의 메모리에만 존재합니다. 본 앱에는 캡처한 이미지를 파일, 로그, 캐시, 임시 파일로 기록하는 지점이 존재하지 않습니다.

3. 본 앱은 '창'이 아니라 '화면 영역'을 캡처합니다

이는 사용 전에 알고 계셔야 할 한계이며, 사용자가 스스로 발견하도록 두지 않고 분명히 밝힙니다.

본 앱은 특정 창이 아니라 화면의 사각형을 캡처하므로, 그 사각형 앞으로 오는 것은 무엇이든 함께 캡처됩니다. 본 앱은 그 영역을 차지한 창이 무엇인지 감시하여 다른 프로그램이 덮으면 읽기를 멈추지만, 그 감시는 완전하지 않습니다.

  • 다른 창이 영역 위로 온 순간과 본 앱이 그것을 알아채는 순간 사이에는 최대 한 번의 캡처 간격만큼 틈이 있습니다.
  • 같은 프로그램의 다른 창은 의도적으로 통과시킵니다. 대화방마다 창을 따로 여는 메신저에서 그것은 사용자가 의도한 동작이기 때문입니다.
  • 웹 브라우저에서 쓰는 메신저에서는 이 감시가 사실상 무력합니다. 영역을 차지한 프로그램이 브라우저이므로 같은 브라우저의 다른 탭과 다른 창이 전부 검사를 통과합니다. 탭은 브라우저 밖에서 구분할 수 없습니다. 대상이 브라우저로 판정되면 본 앱이 세션당 한 번 이를 알립니다.

사용자가 할 수 있는 대응: 읽기 구멍을 메시지 목록에 맞게 좁게 두고, 시작을 누르기 전에 그 뒤에 무엇이 있는지 확인하며, 대화가 끝나면 정지를 누르십시오.

4. 화면 이미지가 기기 밖으로 나가는 경우

본 앱이 캡처한 이미지를 텍스트로 바꾸는 방법은 두 가지이며, 어느 쪽을 쓰는지가 이미지 자체의 전송 여부를 결정합니다.

상황이미지를 읽는 주체이미지가 기기 밖으로 나가는가
읽을 언어를 지정했고, 그 언어의 인식기가 Windows에 설치되어 있는 경우 기기 안의 Windows 내장 인식기 나가지 않습니다. 이미지는 어디로도 전송되지 않습니다.
언어가 자동 감지로 설정되어 있거나, 지정한 언어의 인식기가 Windows에 없는 경우 이미지를 보게 되는 Google의 모델 나갑니다. 캡처한 이미지가 PNG로 Google에 전송됩니다.

이미지는 전송 전에 긴 변이 최대 1024픽셀이 되도록 축소됩니다.

이미지를 받을 수 있는 서비스는 Google 하나뿐입니다. Anthropic, OpenAI, DeepL, Groq, 그리고 사용자가 주소를 직접 입력한 곳에는 이미지가 전송되지 않으며, 이들은 텍스트만 받습니다. 선택한 서비스가 이미지를 볼 수 없고 요청한 언어를 Windows도 읽을 수 없는 경우, 본 앱은 이미지를 다른 곳으로 보내지 않고 멈춘 뒤 그 사실을 알립니다.

이미지를 기기 안에만 두려면

본 앱에서 읽을 언어를 “자동 감지”가 아니라 특정 언어로 지정하고, 그 언어의 Windows 인식기가 설치되어 있는지 확인하십시오. 그러면 읽기가 전적으로 사용자의 컴퓨터에서 이루어지며 이미지는 전송되지 않습니다.

읽을 언어를 “자동 감지”로 두면, 앱이 화면에서 읽어낸 문자를 보고 해당 언어를 스스로 지정할 수 있습니다. 이 경우 이후 캡처는 기기 안에서 처리되어 이미지가 외부로 전송되지 않습니다. 언어가 바뀌면 화면에 알림이 표시되며, 언제든 다시 “자동 감지”로 되돌릴 수 있습니다.

인식된 텍스트는 다음 절에 설명된 대로 선택한 번역 서비스로 여전히 전송됩니다. 언어 지정은 이미지의 전송 여부를 바꾸는 것이지, 서비스 없이 번역이 되게 만드는 것이 아닙니다.

5. 제3자 전송

본 앱은 외부 서비스 한 곳을 호출하여 번역합니다. 어느 곳인지는 사용자가 선택하며, 그 서비스의 계정 자격 증명도 사용자가 직접 제공합니다. 선택된 서비스만 호출됩니다.

본 앱이 지정할 수 있는 서비스는 Anthropic, OpenAI, Google, DeepL, Groq이며, 여기에 사용자가 주소를 직접 입력하는 OpenAI 호환 서비스 항목이 하나 더 있습니다. 이 항목의 경우 데이터는 사용자가 입력한 주소로 전송되며, 그 주소는 사용자 자신이 운영하는 서버일 수도 있고 사용자가 선택한 제3자의 서버일 수도 있습니다.

전송되는 것

  • 읽기 구멍 안에 있는 메시지들의 인식된 텍스트.
  • 입력한 글을 번역하는 기능을 사용할 때, 사용자 본인이 작성한 메시지의 텍스트.
  • 원본 언어와 대상 언어, 그리고 선택한 말투를 명시한 본 앱의 번역 지시문.
  • 요청의 인증 헤더로서의 사용자 API 키.
  • Google에 한하여, 그리고 4절에 설명된 상황에 한하여, 캡처한 이미지.

사용자가 요청할 때만 전송되는 것

  • 설정에서 모델 목록을 새로 고칠 때, 그 서비스가 제공하는 모델 목록 요청. 이 요청에는 API 키 외에 아무것도 담기지 않습니다.
  • 설정에서 연결을 테스트할 때의 짧은 연결 확인 요청.

BABA SOFTWARE는 이 중 어느 것의 수신자도 아닙니다. 본 앱에는 이를 보낼 당사의 서버가 존재하지 않습니다.

각 서비스가 수신한 내용을 어떻게 취급하는지는 본 방침이 아니라 그 서비스의 개인정보처리방침과 약관이 규율합니다. 주소가 고정된 서비스에 대해서는 본 앱이 설정 화면에서 해당 방침을 링크하므로 선택 전에 읽어 보실 수 있습니다. 주소를 사용자가 입력하는 항목에 대해서는 그 주소가 사용자의 것이므로 링크할 방침이 존재하지 않습니다.

6. 클립보드

본 앱은 다음 두 가지 목적으로만 클립보드를 사용합니다.

  1. 사용자가 쓴 글 가져오기 — 사용자가 채팅 입력창에 글을 쓰고 전송 키를 누르면, 앱이 복사 명령을 보내 그 글을 가져옵니다. 이 글은 번역을 위해 사용자가 선택한 번역 서비스로 전송됩니다.
  2. 번역문 입력하기 — 번역된 글을 클립보드에 넣어 입력창에 붙여넣습니다.

작업 전 기존 클립보드 내용을 보관했다가 작업 후 되돌립니다. 다만 앱 자체 입력칸을 사용한 경우, 그리고 붙여넣을 창을 찾지 못해 사용자가 직접 붙여넣도록 안내한 경우에는 번역문이 클립보드에 남습니다.

이 앱은 클립보드를 주기적으로 감시하지 않습니다. 클립보드 읽기는 위 작업이 실행되는 순간에만 일어납니다. 사용자가 이전에 복사해 둔 내용은 복원 목적으로만 읽히며, 외부로 전송되거나 디스크에 저장되지 않습니다.

7. 키보드

먼저 분명히 밝힙니다. 본 앱은 전역 저수준 키보드 훅을 설치합니다. 이는 사용자가 입력 중인 프로그램보다 먼저 키 입력을 볼 수 있게 하는 Windows의 기능이며, 사용자가 작성한 글을 다른 곳에 복사하게 만들지 않고 Enter를 누르는 순간에 번역할 수 있는 것은 이 때문입니다.

이 훅이 여기서 하는 일은 좁으며, 전부 다음으로 한정됩니다.

  • 훅은 앱이 시작될 때 설치되어 앱이 실행되는 동안 유지됩니다. 번역이 실행 중이고 동시에 입력한 글을 번역하는 입력 방식을 선택한 경우가 아니면 아무 일도 하지 않으며, 그 외에는 모든 키가 그대로 지나갑니다.
  • 보는 키는 Enter 하나입니다. 그 외의 키는 검사하지 않고 그대로 넘깁니다.
  • Enter는 본 앱이 읽고 있는 대화 창이 곧 사용자가 입력 중인 창일 때만 처리합니다. 그 밖의 곳에서 누른 Enter는 손대지 않고 넘깁니다.
  • 대부분의 대화 프로그램에서 줄바꿈인 Shift+Enter는 결코 건드리지 않습니다.
  • 훅이 내리는 유일한 판단은, 그 Enter를 통과시킬지 아니면 먼저 번역할 수 있도록 붙잡아 둘지입니다.

이것이 키로거가 아닌 이유

키로거는 사용자가 입력한 문자를 기록하여 어딘가로 보냅니다. 본 앱은 둘 다 하지 않습니다. 본 앱은 입력한 문자를 읽지 않습니다. Enter 외의 키는 검사하지 않고, 어떤 키 입력도 저장하지 않으며, 어떤 키 입력도 전송하지 않습니다.

번역되는 텍스트는 훅에서 나오지 않습니다. 그것은 Enter를 누른 뒤 6절의 클립보드 방식으로 대화 프로그램의 입력창에서 복사한 것이며, 사용자가 이미 작성을 마치고 보내려던 메시지이지 입력 과정의 기록이 아닙니다.

8. API 키의 저장

입력한 키는 본 앱의 설정 파일에 저장됩니다. 이 파일은 사용자별 애플리케이션 데이터 폴더에 settings.json 파일 하나로 저장됩니다. 실제 경로는 설치 방식(일반 설치 / Microsoft Store 패키지)에 따라 다르며, 어느 경우든 현재 로그인한 Windows 사용자 계정에만 속하는 위치입니다.

그 파일 안에서 키는 Windows 데이터 보호 API(DPAPI)의 현재 사용자(current user) 범위로 암호화되며, 응용 프로그램 고유의 추가 엔트로피 값이 함께 사용됩니다.

그 결과 저장된 키는 그 컴퓨터의 해당 Windows 계정에서만 복호화할 수 있습니다. 다른 계정이나 다른 컴퓨터로 복사하면 읽을 수 없으며, 본 앱은 키가 설정되지 않은 것으로 취급합니다.

키는 그것이 속한 서비스로만, 해당 요청의 인증 헤더로서 전송됩니다. 당사로 전송되지 않으며, 다른 어떤 서비스로도 전송되지 않습니다.

9. 번역 기억

본 앱은 실행 중에 이미 받아 둔 번역을 기억하여, 대화를 위아래로 스크롤할 때 같은 메시지에 두 번 비용을 치르지 않게 합니다.

  • 이 기억은 실행 중인 프로그램 안에만 존재합니다. 디스크에 기록되지 않습니다.
  • 최대 1,500건을 보관하며, 그것을 넘으면 오래된 것부터 버립니다.
  • 서비스, 언어 쌍, 말투 중 하나라도 바꾸면 즉시 비웁니다.
  • 앱을 닫으면 사라집니다. 종료 시 내보내거나 저장하는 것은 없습니다.

10. 기기에 저장되는 것

본 앱이 기록하는 파일은 8절에서 설명한 사용자별 애플리케이션 데이터 폴더의 settings.json 하나입니다. 이 파일에는 설정만 들어 있습니다.

  • 선택한 서비스, 그리고 설정해 둔 서비스마다: 암호화된 API 키, 선택한 모델, 그 서비스가 사용자가 입력한 주소를 쓰는 경우 그 주소.

  • 표시 방식과 입력 방식.
  • 프레임 색, 말풍선 색, 말풍선 글자 색.
